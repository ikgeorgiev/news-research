Source intake

tools/news_sources.py imports saved Yahoo GraphQL responses, reviewed Godel
terminal captures, the published FC GNW HTML listing, NEWSnet GNW RSS, and the
published Guggenheim issuer RSS, and the published XAI distribution RSS into a
dedicated local review database.
It does not turn the existing Yahoo RSS source into a direct Yahoo connection.
It also does not claim to implement an undocumented Godel API.

  python tools/news_sources.py init .tmp/new-source-review.sqlite
  python tools/news_sources.py import .tmp/new-source-review.sqlite .tmp/capture/manifest.json
  python tools/news_sources.py report .tmp/new-source-review.sqlite .tmp/reviewed-cases.json .tmp/new-source-report.json

Use a new SQLite filename. An unrelated existing database is rejected before
any write. Reimporting the identical manifest/payload is idempotent. Distinct
receipts are retained even when they repeat a story; first sightings remain
separate by route, clock, receipt kind and new/history classification. A later
200 cannot clear a saved refusal. There is no live-request command.

Manifest format (version 1)

Required fields: route, request_url, received_at, receipt_kind, classification,
http_status, payload_file and payload_sha256. payload_file is relative to the
manifest directory and must remain inside it after path resolution. The digest
is the SHA-256 of its exact bytes. Payload cap is 4 MiB (Yahoo parser: 1 MiB),
manifest cap 64 KiB, response cap 250 records. Reports cap at 10,000 observations.

Routes and accepted request URLs are explicit in news_sources.py ROUTES.
receipt_kind is network_response, retained_response, manual_capture or cached.
classification is baseline, new, historical or unknown_history. A network
receipt additionally requires timezone-aware request_started_at and clock_id.
Yahoo additionally accepts requested_symbol and tab (default: press releases).
Use synthetic_fixture: true for examples; those are excluded from live receipts.

For Godel, receipt_kind must be manual_capture. Payload is our reviewed format:
  {"version":1,"entries":[{"local_id":"capture-1","title":"Exact copied headline",
    "original_source_link":"https://www.businesswire.com/news/home/20261109123456/en/",
    "observed_at":"2026-11-09T14:00:20Z","displayed_time_local":"2026-11-09 16:00:00",
    "source_label":"Business Wire","filters":"Record the visible filter state"}]}
This example is synthetic. A displayed publication time is never used as a
network receipt. The retained October 30 capture format is also supported.
Its missing headlines remain missing; they are not borrowed from our database.

Reviewed-case input uses a cases array with positive article_id, title, date,
wire_identity and/or canonical_url. Exact original link plus headline matches,
conflicting headlines, ambiguous cases and title/date-only candidates are
reported separately. Local FC/Godel/WordPress/Yahoo identifiers never become
wire identities. Related symbols never become validated fund assignments.
Missing cases in a finite saved response are unobserved, not established misses.

Weekday snapshot

  python tools/news_weekday_snapshot.py .tmp/new-production-snapshot.json --minutes 65

This performs one local /health read (five-second timeout, no redirects), reads
the actual backend process identities, and uses a repeatable read-only database
transaction on the verified local cef_news mapping. Each statement has a
five-second timeout. Choose a window of 1–360 minutes. It reads at most 1,000
recent articles, 10,000 associated ticker rows and 100 recent failed runs.
Truncation is explicit. It reads FC state read-only and scans at most 8 MiB of
timing logs, restricted to current app PIDs and the selected time window.

No website listing/body is requested. No SSE observer, process change, setting
change or database mutation occurs. first_seen_at and created_at are preserved
database labels, not renamed as measured commit. The old research timing expiry
is unchanged; absent traces are reported as gaps. Article body file presence
is only an inventory check. Audit actual structure with:

  python tools/news_validation.py reader .tmp/new-production-snapshot.json .tmp/new-reader-report.json --archives data/article-bodies

The actual browser Delivery check remains a separate, user-visible bounded
session. A database snapshot cannot establish physical screen delivery.
